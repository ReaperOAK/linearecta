# LineaRecta

**Interactive geometry solver and Canvas visualizer for point-to-line shortest distance.**

LineaRecta is a lightweight, zero-dependency client-side web application that calculates and visually plots the shortest perpendicular distance from an arbitrary 2D coordinate to a linear equation ( + By + C = 0$).

---

## Features

- **Real-Time Canvas Rendering:** Dynamically draws Cartesian coordinate bounds, the target line, the arbitrary point, and the perpendicular projection vector via HTML5 Canvas.
- **Instant Mathematical Feedback:** Solves  = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$ synchronously on every input change.
- **Zero Dependencies:** Pure vanilla HTML, CSS, and modern JavaScript with no external runtime libraries.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Graphics:** HTML5 Canvas API
